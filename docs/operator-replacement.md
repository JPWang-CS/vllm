# 外部算子接入

算子仓负责生成可安装或可加载产物。模型项目负责把对应调用接入前向路径。两个仓可以独立发布和升级。

| 外部产物 | 本项目使用方式 | 验证依据 |
|---|---|---|
| wheel / Torch 扩展 | 安装到项目私有 Python 环境，适配器导入并调用 | 实际模块或 .so 路径、输出与原生对照 |
| 自定义 OPP 包 | 安装器明确指定项目私有目录，运行时配置搜索路径 | 实际 vendor 路径、算子分支与调用记录 |
| ACLNN 动态库 | 项目适配器链接或加载，声明内存和 stream 合同 | 实际加载库、设备执行与输出 |
| 独立程序 | 作为单算子验证工具运行 | 命令、退出码、精度与计时 |

`models/<model>/changes/<name>/change.yaml` 保存适用平台、范围、依赖、冲突、环境覆盖及验证命令。`external-op.example` 演示接口，其验证脚本由具体算子实现提供。

调用验证应保存：目标实现的加载路径、实际输入规格、原生/替换输出误差、适配器命中数和回退数。框架执行验证命令并保存日志；命令本身必须检查这些内容，不能仅打印成功。

模型特定的 forward 替换保存在该模型目录的适配器内。全局覆盖公共 OPP 或修改其他项目 Python 环境会影响无关实验，因此安装位置和运行路径必须由本项目配置明确指定。
