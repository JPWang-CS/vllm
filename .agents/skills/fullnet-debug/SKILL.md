# 整网调试

先读取实验 `state.json`、冻结配置和失败阶段的日志。记录首个错误、调用路径、设备映射、实际包版本与加载路径，再提出修复。

按已发生的步骤定位：环境和权限、模型加载、通信组、KV cache、首个请求、目标算子、数值检查。输入预算错误在发送请求前解决；设备访问和库加载失败先检查路径及容器配置。保留错误现场，修改后创建新实验。

数值问题先确定最早偏离的输出或中间阶段。用固定输入和原阈值重现，检查 dtype、shape、layout、mask、归约和异常值。修复后做同条件对照，不能用放宽阈值替代解释。

远端只执行已批准的项目脚本；停止本任务服务后确认进程、端口和设备释放。对共享驱动、CANN、容器映射或设备复位的需求交给环境管理，不自动修改。
