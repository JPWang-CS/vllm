# 整网与算子迭代

读取目标模型的原生基线、实际 profiler、负载与精度协议。先确定耗时最大的计算、通信或 Host 间隔，选一项修改，说明预期减少的成本和可能增加的成本。

算子修改由独立算子仓构建，框架使用 `fullnet-replace` 验证调用与精度，再用 `fullnet-profile` 采集相同负载。系统修改也保存在模型的独立 `changes/` 中，固定并行、batch、序列长度及采样条件。

比较算子设备时间、整网请求时间、TTFT/TPOT、吞吐、显存和精度。报告包含适用范围、回退条件、收益或退化、测量次数及原始实验位置。多项修改分别验证后再建立组合实验。

可接受的原生实验加入该模型基线索引，保留旧基线引用；失败实验保留结果和原因。后续方向来自实际瓶颈与测量，不以启用某个优化 API 代替收益证据。
